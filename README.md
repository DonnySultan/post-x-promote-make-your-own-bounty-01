An entry for make.fun's "Promote make.fun's make-your-own-bounty post on X" bounty. The entry is one post on X that quotes make.fun's make-your-own-bounty post, with a photo of its own attached and the entrant's play code in its text; places go by the post's replies, reposts and quotes. This repository hands in the post's address: `main.ts` (Node 22, standard library only) copies `POST.json` from the repository root to `/output/POST.json`, where the house's gate reads it.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
